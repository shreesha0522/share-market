Methodology Note

Market data: daily OHLC trading records for 10 companies across 5 sectors, sourced from NEPSE via a public historical data archive, cleaned and aggregated in Python (pandas). Volatility = standard deviation of daily percentage returns; total return = 5-year price change. Survey data: structured questionnaire (see survey_questionnaire.md) covering demographics, investment profile, and 10 Likert-scale challenge items, distributed via Google Forms. The chart above uses synthetic placeholder data until real responses are collected — swap in the exported CSV and rerun analysis.py to refresh every number and chart on this page automatically.

Built with Python (pandas, matplotlib) for the analysis pipeline and this static dashboard for presentation. Data pipeline: scripts/analysis.py → website/data.json → this page.
