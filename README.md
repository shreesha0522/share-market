# Analysis and Identification of Challenges Faced by New Investors in the Share Market

Using Survey-Based and Market Data Analysis.

## Overview

This project analyzes the Nepal Stock Exchange (NEPSE) alongside investor-reported
survey data to identify the key challenges faced by new investors. It combines:

- **Real market data**: 5-year daily OHLC data for 10 companies across 5 sectors
  (Banking, Hydropower, Insurance, Investment, Telecom), sourced from NEPSE.
- **Survey data**: A structured questionnaire covering investor demographics,
  investment profile, and 10 Likert-scale challenge items, distributed via Google Forms.
- **Statistical analysis**: Correlation and regression analysis linking investing
  experience, portfolio size, and trade frequency to overall challenge scores.
- **A web dashboard**: A static, data-driven site presenting all findings —
  volatility charts, sector risk/return, survey rankings, and regression results.

> ⚠️ **Status note:** Survey data is currently **synthetic placeholder data**,
> used to build and test the analysis pipeline end-to-end. Real Google Forms
> responses will be substituted before final submission, at which point the
> pipeline (`analysis.py`) can be rerun to regenerate all numbers and charts
> automatically — no changes needed to the website code itself.

## Project Structure

```

│   └── analysis.py           # Core pipeline: cleans data, computes metrics,
│                              # runs statistics, generates charts + website/data.json
├── outputs/
│   ├── charts/                # Matplotlib PNGs for the written report
│   ├── company_metrics.csv
│   └── sector_metrics.csv
├── website/
│   ├── index.html             # Static dashboard (Chart.js)
│   └── data.json              # Generated by analysis.py — powers the dashboard
└── README.md
```

## Pipeline

```
Market CSVs + Survey CSV  →  scripts/analysis.py  →  website/data.json  →  website/index.html
```

Run the pipeline with:

```bash
python scripts/analysis.py
```

This produces:
1. Cleaned company/sector metrics (returns, volatility, avg. daily volume)
2. Survey analysis (challenge rankings, breakdowns by experience/age)
3. Correlation matrix + OLS regression on challenge scores
4. Chart PNGs for the report (`outputs/charts/`)
5. `website/data.json`, which the dashboard reads directly (no backend required)

## Dashboard Sections

1. **Market Overview** — volatility by company, sector risk vs. return, full metrics table
2. **Survey Findings** — ranked investor challenges, challenge score by experience
3. **Statistical Analysis** — correlation and regression results
4. **Methodology** — data sources, computation notes, synthetic-data disclosure

## Tech Stack

- **Analysis**: Python (pandas, numpy, statsmodels, scipy, matplotlib)
- **Website**: Static HTML/CSS/JS, Chart.js — no backend, no database, no login required
- **Data flow**: One-way, file-based (CSV → JSON → static site)

## Ethics

This project involves primary research with human participants (the investor
survey). Participants are informed of the study's purpose, and responses are
collected and analyzed anonymously with no personally identifying information
retained in the dataset or dashboard.
