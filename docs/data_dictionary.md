# Data Dictionary

## Market data (`data/market/<TICKER>.csv`)

One CSV file per company, containing daily trading data.

| Column | Type | Description |
|---|---|---|
| `published_date` | date (YYYY-MM-DD) | Trading date |
| `close` | float | Closing price (NPR) |
| `traded_quantity` | integer | Number of shares traded that day |

**Known data quality note:** some files contain a small number of duplicate
dates (see `scripts/validate_data.py` for a full report). These are handled
defensively in `analysis/market.py` by keeping the first occurrence and
dropping subsequent duplicates.

## Survey data (`data/survey/survey_synthetic.csv`)

**⚠️ Currently synthetic placeholder data** — generated by
`scripts/generate_synthetic_survey.py` to build and test the analysis
pipeline. Must be replaced with real respondent data before being presented
as primary research findings.

| Column | Type | Description |
|---|---|---|
| `response_id` | integer | Row identifier |
| `age_group` | category | 18-24, 25-34, 35-44, 45-54, 55+ |
| `gender` | category | Self-reported gender |
| `education` | category | Highest education level |
| `occupation` | category | Current occupation |
| `monthly_income` | category | Income bracket (NPR) |
| `years_investing` | category | Investing experience: <1 year, 1-3 years, 3-5 years, 5+ years |
| `portfolio_size` | category | Portfolio value bracket (NPR) |
| `trade_frequency` | category | How often the respondent trades |
| `sectors_invested` | text (comma-separated) | Sectors the respondent holds positions in |
| `info_source` | category | Primary source of investing information |
| `lacks_knowledge` | integer (1-5) | Agreement: lacks financial knowledge |
| `hard_to_access_info` | integer (1-5) | Agreement: hard to access reliable info |
| `volatility_difficulty` | integer (1-5) | Agreement: market volatility is hard to handle |
| `broker_platform_issues` | integer (1-5) | Agreement: broker/TMS platform issues |
| `regulatory_confusion` | integer (1-5) | Agreement: regulatory/tax confusion |
| `emotional_control` | integer (1-5) | Agreement: struggles with fear/greed |
| `limited_capital` | integer (1-5) | Agreement: limited capital is a barrier |
| `misled_by_rumors` | integer (1-5) | Agreement: misled by rumors/tips |
| `ipo_process_confusing` | integer (1-5) | Agreement: IPO/rights process is confusing |
| `lacks_mentorship` | integer (1-5) | Agreement: lacks mentorship |
| `profitable_experience` | category | Yes / No / Break-even / Not sure |
| `confidence_change` | category | How confidence has changed since starting to invest |
